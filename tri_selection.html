Tri Selection

Le tri selection est un algorithme de tri simple et intuitif. Il consiste à chercher le minimum dans le tableau et à le placer en début de tableau. L'algorithme est répété n-1 fois pour un tableau de taille n.

Fichier python Tri Selection 
            def tri_selection(l : list) -> list:
                for i in range(len(l)-1):
                    min = i
                    for j in range(i,len(l)):
                        if l[j] < l[min]:
                            min = j
                        l[min],l[i] = l[i],l[min]
                return l
