Tri Insertion

Le tri par Insertion est un algorithme de tri qui consiste à insérer un élément à sa place dans un tableau trié. Cet algorithme est basé sur la construction d'une liste triée à partir d'une liste non triée.

Fichier python Tri Insertion 
            def tri_insertion(tab : list) :
                for i in range(1,len(tab)):
                    val_à_inserer = tab[i]
                    j = i-1
                    while tab[j] > val_à_inserer and j >=0 :
                        tab[j+1] = tab[j]
                        j -= 1
                    tab[j+1] = val_à_inserer
                return(tab)
